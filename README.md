# Library Catalog

A terminal-based library management system built in Python for organizing and tracking books.

## Features
- Add a new book with title, author, and category
- View all saved books in a formatted table
- Search for a book by title
- Edit an existing book's details
- Delete a book with confirmation
- Simple, interactive terminal interface

## How to Run
1. Make sure Python is installed on your system.
2. Run the program
3. Choose an option from the menu using its number or name (e.g., `1` or `add book`).

## Menu Options
1. Add Book
2. View All Books
3. Search Book
4. Edit Book
5. Delete Book
6. Exit
